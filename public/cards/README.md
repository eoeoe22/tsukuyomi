# 카드 문법 (cards/*.wiki)

랜드마크 카드(`#focusCard`)의 내용은 이 폴더의 `{kind}.wiki` 파일에 적는다.
`torii.wiki`, `moon.wiki`, `mirror.wiki`가 있다.
렌더러는 `tsukuyomi.markup.js`이고, Cloudwiki 문법에서 위키 전용 기능을 뺀 포크다.

- **미리보기:** `` ` `` 또는 F12로 디버그 패널을 연다. **카드 미리보기**에서 원문을 고치면 카드에 바로 반영된다.
  메모리에만 반영되므로 **복사**해서 이 파일들에 붙여넣어 저장한다.
- **폴백:** 파일을 못 읽거나 렌더러가 로드되지 않으면 `tsukuyomi.focus.js`의 내장 표(NAMES/DESCS/BODIES)가 대신 보인다.
- **기반 문법:** 기본은 Markdown(marked)이다. 원시 HTML은 sanitize(DOMPurify)되고 `<script>` 등은 글자로 보인다.

## 카드 머리 (`:::meta`)

```
:::meta
title = 토리이
lead = 카드 제목 아래 한두 줄 설명
year = 1600
:::
```

| 키 | 용도 |
| --- | --- |
| `title` | 카드 제목. 없으면 기본 이름(토리이/달/미러볼)을 쓴다. |
| `lead` | 제목 아래 설명. 없으면 숨긴다. |
| 그 밖 | 문서 변수. 본문에서 `{{{@year}}}` 또는 기본값을 붙인 `{{{@없는키\|기본}}}`로 쓴다. |

## 텍스트 서식

| 문법 | 결과 |
| --- | --- |
| `**굵게**` `*기울임*` `__밑줄__` `~~취소선~~` | 서식 |
| `` `코드` `` | 인라인 코드 (안의 문법은 처리하지 않음) |
| `==텍스트==` | 형광펜 |
| `{bg:#333}==텍스트==` `{color:#f00}==텍스트==` | 배경색 / 글자색 |
| `{palette:warning}==텍스트==` | 빌트인 팔레트 (아래 표) |
| `{fs:lg}==텍스트==` | 글자 크기: `xs` `sm` `lg` `xl` `xxl` |
| `줄{br}바꿈` | 강제 줄바꿈 |
| `{hr}` | 얇은 구분선 |
| `## 제목` | 헤딩 |
| `## 제목 {collapse}` | 처음엔 접혀 있는 섹션. 하나라도 있으면 모든 헤딩이 접기 가능해진다. |

**팔레트:** `primary` `secondary` `success` `info` `warning` `danger` `muted` (커스텀 팔레트는 없음).
색 값은 `#hex`, `rgb()`, `hsl()`, 색 이름을 쓸 수 있다.

## 아이콘 · 인라인 컴포넌트

| 문법 | 설명 |
| --- | --- |
| `{bi:moon-stars}` | [Bootstrap Icons](https://icons.getbootstrap.com/) 1.13.1 (MDI는 지원하지 않음) |
| `{badge:텍스트}` | 작은 라벨 칩 |
| `{tag:텍스트}` | 태그 칩 |
| `{button:열기\|https://example.com}` | 링크 버튼 (외부 링크는 새 탭) |
| `{stat:42\|라벨}` | 수치 강조 박스 |
| `{kbd:Ctrl+C}` | 키보드 키 |
| `{progress:70\|라벨}` | 진행도 바 |
| `{progress:auto\|라벨}` | 바로 위 체크리스트의 완료 비율 |

배지, 버튼, 진행도 바 같은 컴포넌트 앞에 `{palette:}` `{bg:}` `{color:}`를 붙이면 그 색이 들어간다.
예: `{palette:primary}{badge:NEW}`

## 각주

| 문법 | 설명 |
| --- | --- |
| `본문[* 각주 내용]` | 번호 각주 (내용에 서식 사용 가능) |

## 이미지 · 임베드

| 문법 | 설명 |
| --- | --- |
| `![설명](URL)` | 이미지 |
| `![설명](URL){size:small}` | 크기: `icon` `small`(25%) `medium`(50%) `full` |
| `{align:center}` | 이미지 정렬: `left` `center` `right` (이미지 뒤에 붙임) |
| `{caption:설명}` | 이미지 캡션 (이미지 뒤에 붙임) |
| `{embed:https://youtu.be/...}` | YouTube / 니코동 / Spotify / Google 지도 삽입 |
| `{embed:URL}{size:small}` | 임베드 크기: `small` `medium` |

## 표

```
{table:center}{sortable}{caption:표 제목}
| 이름 | 값 |
| --- | --- |
| a | {bg:#123456}10 |
| b | {<} |
```

| 문법 | 설명 |
| --- | --- |
| `{table:left\|center\|right}` | 표 정렬 (표 바로 윗줄) |
| `{w:50%}` | 표 너비. 구분 행 칸에 쓰면 열 너비가 된다. |
| `{caption:제목}` | 표 제목 |
| `{sortable}` | 헤더를 클릭해 정렬 |
| `{sticky-header}` | 세로 스크롤 시 헤더 고정 |
| `{row-header}` | 첫 열을 행 헤더로 |
| 셀 안 `{bg:색}` `{color:색}` | 셀 색 |
| 셀 안 `{<}` `{>}` `{^}` `{><}` | 왼쪽 / 오른쪽 / 위쪽 셀과 병합, 양쪽 반분할 |

구분 행(`| --- |`) 없이 `| 키 | 값 |` 줄만 쓰면 첫 행이 헤더가 된다.
인포박스 안에서는 일반 행처럼 보인다.

## 블록 (`:::`)

블록은 `:::이름 제목` 줄로 열고 `:::` 줄로 닫는다. 서로 중첩할 수 있다.
제목 줄에 `{palette:}` `{bg:}` `{color:}`를 쓰면 블록에 색이 들어간다.

### 콜아웃

`:::info` `:::tip` `:::success` `:::warning` `:::danger` `:::note`

```
:::info 참고
콜아웃 본문
:::
```

### 카드 · 레이아웃

```
:::card {palette:info} 제목
본문
:::

:::grid {cols:2}
:::card A
:::
:::card B
:::
:::

:::infobox 정보
| 이름 | 토리이 |
| 높이 | 8m |
:::
```

| 블록 | 옵션 |
| --- | --- |
| `:::grid` | `{cols:2~6}` `{template:1-2}` `{gap:sm\|md\|lg}` `{align:start\|center\|stretch}` |
| `:::row` | 가로 한 줄 배치 (넘치면 가로 스크롤) |
| `:::canvas` + `:::area` | 12컬럼 배치. `{span:N}` `{panel}` `{order:N}` |
| `:::infobox` `:::float` | `{left}` `{right}` `{span:3~6}` |
| `:::gallery` | `{cols:2~6}`. 본문 이미지들을 정사각 썸네일로 |
| `:::embed` | 강조선 인용 박스 (안의 미디어 URL은 임베드) |

카드 폭이 340px이라 다음처럼 바뀐다:
- `grid`는 `{cols:2}`와 `{template:1-1}`만 2열로 유지하고, 나머지는 1열로 쌓인다.
- `canvas`는 1열로 쌓인다.
- `float`와 `infobox`는 옆으로 띄우지 않고 본문 흐름에 놓인다.
- `gallery`는 최대 3열이다.

### 탭 · 아코디언 · 스텝

```
:::tabs
:::tab {icon:bi-1-circle} 첫째
탭 1
:::
:::tab 둘째
탭 2
:::
:::

:::accordion
:::item {open} 항목 A
A
:::
:::item 항목 B
B
:::
:::

:::steps
:::step {status:done} 준비
:::
:::step {status:current} 진행
:::
:::step 마무리
:::
:::
```

| 옵션 | 설명 |
| --- | --- |
| `:::accordion {multiple}` | 여러 항목을 동시에 펼칠 수 있게 (기본은 하나만) |
| `:::item {open}` | 처음부터 펼침 |
| `:::step {status:done\|current\|todo}` | 단계 상태 |
| `{icon:bi-이름}` | 탭이나 항목 제목 앞 아이콘 |

## 코드 블록 · 차트

````
```js
const a = 1;   // Prism 하이라이트 (필요할 때만 CDN 로드)
```

```chart
type: bar
labels: [1Q, 2Q, 3Q]
series:
  매출: [120, 150, 90]
  비용: [80, 95, 70]
```
````

- **차트 `type`:** `bar` `line` `pie` `doughnut` `radar`.
- **시리즈:** `series:` 아래에 들여써서 `이름: [숫자, ...]`를 최대 8개까지 적는다.
- **개수:** 각 시리즈의 값 개수는 `labels` 개수와 같아야 한다.
- **로딩:** Chart.js 4.5.1은 차트가 있을 때만 로드된다.

## 지원하지 않는 Cloudwiki 문법

카드 렌더러에서는 다음 문법을 쓸 수 없다:
- `[[문서 링크]]`
- 틀(`{{틀}}`, `{{#if}}` 등 파서 함수)
- 확장
- 멘션
- 분류
- 커스텀 팔레트
- `{mdi:}` 아이콘
- 헤딩 번호와 목차
- Mermaid

이런 문법은 처리되지 않고 글자로 남는다.
