# 회전체(lathe) 기법 상세 — 「회전하는 죽순」

## 1. 프로파일 → 반지름 표

원본은 SVG path 의 오른쪽 절반 베지어 3개를 직접 적어 각 400 등분 샘플링했다. 템플릿은 일반화해서 `SVGPathElement.getPointAtLength()` 로 전체 path 를 4000 점 샘플링하고, 오른쪽 절반(x ≥ CX)의 연속 구간을 경로 순서대로 잘라 위→아래 방향의 `PROFILE = [[y, r], …]` 을 만든다. path 시작점이 어디든, 감는 방향이 어느 쪽이든 동작한다.

`PROFILE` 은 호 길이 기준이라 수평에 가까운 바닥·꼭대기도 촘촘하다. 여기서 두 가지를 만든다.

- `R_LUT[y]`: 정수 높이마다 `PROFILE` 의 이웃 두 점을 **선형 보간**. 반올림+max 로 모으면 계단이 생겨 `dr/dy` 가 흔들리고, 가장 넓은 지점에서 앞면 판정이 깜빡여 실루엣을 따라 점선이 생긴다.
- 표면 전체를 훑는 작업(음영 굽기)은 `R_LUT` 가 아니라 `PROFILE` 을 직접 순회. 높이 등간격으로 훑으면 바닥에서 반지름이 건너뛰어 동심원 무늬가 생긴다.

```js
rAt(y)  // 선형 보간된 반지름
drdy(y) = rAt(y+0.5) − rAt(y−0.5)   // 법선 계산용 기울기
```

축대칭 조건: 실루엣이 좌우 대칭이어야 하고, 높이마다 반지름이 하나여야 한다(가로로 오목하게 파고드는 형태는 바깥 반지름만 남는다).

## 2. 투영

```js
function project(th, y) {
  const a = th + rot, r = rAt(y);
  const x = r*sin(a), z = r*cos(a), u = YC − y;          // u: 위쪽 양수 높이
  const front = drdy(y)*st + cos(a)*ct > 0;              // 앞면 판정
  return { x: CX + S*x, y: OY − S*(u*ct − z*st), front };
}
```

법선 유도: 높이 h(위로 양수)에서 반지름 r(h) 인 회전체의 바깥 법선 ∝ `(sin a, −dr/dh, cos a)`. h = YC − y 이므로 `−dr/dh = dr/dy` → `(sin a, dr/dy, cos a)`. x축으로 T 만큼 기울인 뒤 z' = `n_y·sinT + n_z·cosT`.

꼭짓점 근처(`y ≤ Y0`, `y ≥ Y1−1`)는 법선이 불안정하므로 front=false 로 잘라낸다.

## 3. 실루엣

높이 1px 마다 단면 원을 기울이면 중심 `cy = OY − S·(YC−y)·cosT`, 반지름 `rx = S·r`, `ry = rx·|sinT|` 인 타원. 이 타원들을 한 Path2D 에 모두 넣으면 nonzero 채움으로 합집합이 된다. T=0 이면 원래 실루엣과 정확히 일치.

외곽선: `lineWidth = 2·두께` 로 stroke 한 뒤 같은 path 를 fill → 안쪽 절반이 덮여 바깥쪽만 남는다. 타원 경계선들이 내부에 비치지 않는 깔끔한 외곽선이 된다.

## 4. 표면 무늬 곡선

곡선은 `θ → y` 함수. 원본 죽순 껍질:

```js
COUNT=9, TOP0=45, GAP=40, DROP=150, TURN=2π/3
sheath k: top = TOP0 + k·GAP, th = k·TURN
edgeY(k, θ) = top + DROP·(1 − (1 − g)^1.6),  g = |wrap(θ − th)| / π
```

`g` 가 0(끝)일 때 top, 반대편(π)에서 top+DROP. 지수 1.6 은 끝 부근을 거의 직선(∧ 모양)으로, 반대편 최저점을 부드럽게 만든다.

가림 규칙: 아래(바깥) 껍질 j > k 의 가장자리보다 y 가 크면(더 아래) 덮임.

```js
hidden(k, θ, y) = ∃ j>k : y > edgeY(j, θ) + 0.5
```

θ 를 720 등분해 `front && !hidden` 인 연속 구간만 폴리라인으로 잇는다. 그린 뒤 몸통 path 로 clip.

다른 무늬 예:
- 나선 띠: `y = Y0 + (θ/2π + k)·pitch` (θ 범위를 여러 바퀴로)
- 가로 고리: `y = 상수` (θ 무관)
- 세로 줄: 곡선을 `y → θ` 로 바꿔 y 를 샘플링 (`project(th0, y)`)

## 5. 축대칭 음영 굽기

`PROFILE` 의 각 점(호 길이 순)마다 둘레 0.5px(화면 기준) 간격으로 표면을 찍어, 이웃 점 차분 `(dy, dr)` 로 앞면 판정(`dr·sinT + dy·cosφ·cosT > 0`)을 통과한 보이는 점에 alpha 를 2×2 픽셀로 최대값 기록 → ImageData. 원본은 바닥 중심에 가까울수록(반지름 50 이하 완전 불투명, 110 이상 0, smoothstep) 선 색으로 어두워지게 해서 껍질 선 끝을 덮었다. 음영 함수가 0 인 높이(가장 넓은 지점)부터 시작해야 띠가 생기지 않는다.

비용이 크므로 기울기 변경 시에만 수행. 회전과 무관한 이유: 음영 함수가 (y, r) 만의 함수라서.

## 6. 고정 배율

```js
for T in 0..90°: ext = max(ext, 투영 높이 범위)
S = min(1, (Y1−Y0)/ext)
```

기울기마다 `OY` 를 투영 범위 중심이 캔버스 중앙에 오도록 재설정.

## 원본 값

캔버스 300×440, CX 150, 외곽 y 20~420, YC 220, 색 body `#6e625f` / outline `#2b2230` / line `#1e1a1c`, 선 두께 3.5, 1회전 12초.
