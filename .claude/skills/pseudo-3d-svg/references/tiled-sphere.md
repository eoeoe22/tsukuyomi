# 타일 구 기법 상세 — 「미러볼 SVG 생성기」

## 1. 투영

```js
V(lat, lon, s):  x = cos(la)sin(lo), y = sin(la), z = cos(la)cos(lo)
                 return [x, y·ct − z·st, y·st + z·ct]
Pj = [C + R·x, C − R·y']
```

단위구라 반환 벡터가 위치이자 법선. 회전은 `lon + rotDeg`. 원본 값: 캔버스 440, C 220, R 200, 기본 기울기 −32°(아래에서 올려봄), 1회전 40초.

## 2. 타일 배치

- 행: 위도 −90 부터 `step`° 간격, `rows = ceil(180/step)`.
- 행의 타일 수: `n = max(4, round(360·cos(mid)/step))` → 극으로 갈수록 줄어 타일이 대략 정사각형 유지.
- 폭 편차: 각 타일 가중치 `1 ± jit` 를 정규화해 360° 를 채움.
- 행 시작 경도: `rnd()·off·(360/n)` → 세로 줄눈이 행마다 엇갈림.
- 난수: 시드 고정 mulberry32. 배치용, 법선 요동용, 밝기 편차용을 각각 `seed ^ 상수` 로 분리해 한 파라미터를 바꿔도 다른 것이 흔들리지 않게.

원본 기본값: step 9.5, gap 0.14, jit 0.06, off 1, seed 11.

## 3. 타일 그리기

1. 타일 중심 `(mid, lon0 + tw/2)` 의 z' ≤ 0 이면 컬링.
2. 네 모서리 투영 → `pts`. 무게중심 쪽으로 `K = 1 − gap` 배 축소 → `fx`.
3. `pts` 를 옆면색으로, `fx` 를 앞면색(또는 sheen 그라디언트)으로 채운다. 둘 사이 틈이 경사면처럼 보인다. 바탕 원은 줄눈색.
4. 모든 타일을 그린 뒤 `fx` 윗변(3→2)에 `rgba(222,244,248,0.9)` 1.2px, 아랫변(0→1)에 `rgba(0,0,0,0.2)` 1px.

## 4. 반사 모델 `lit()`

```
n   = 요동된 법선 (lat + jLat·1.2°, lon + jLon·1.2°)
nz  = max(0, n.z)
bb  = (amb 0.30 + glow 1.15 · max(0, −n.y)^1.4) · (0.45 + 0.55·nz)   // 아래에서 오는 빛
pole= smoothstep(1 − 남극각거리/poleR)                                 // 남극 중심 원형 광
b   = bb + pole세기 · pole · 1.2
b < 1 : 앞면 = mix(dark, tile, clamp((b + 0.5·(1−nz)³)·(1−teal) + tjit·…))   // 은빛 + 프레넬 림
b ≥ 1 : 앞면 = mix(tile, light, b − 1)
옆면  : w = clamp((1.2 − b)/0.4)  → 어두운 쪽은 밝은 줄눈색, 밝은 쪽은 앞면×[0.5,0.6,0.64] 그늘
```

템플릿은 광원을 `LIGHT` 벡터 하나로 일반화했다(`max(0, n·L)^pw`). 원본의 "아래에서 비춤"은 `L = (0, −1, 0)` 에 해당.

법선 요동(`njit`)이 미러볼다움의 핵심: 0 이면 매끈한 구에 격자 그린 것처럼 보이고, 1~2° 면 조각마다 반사가 달라져 반짝인다.

**sheen**: 앞면 대각선(fx[0]→fx[2]) 선형 그라디언트, stop 0 = 본색×(1−0.3·sw), 0.5 = 본색, 1 = 본색→(244,251,255) 쪽 sw/2. `sw = w·sheen`. 밝기 편차가 클수록 일부 타일은 반대 대각선(fx[1]→fx[3])을 써서 반짝임 방향을 흩뜨린다.

## 5. 오버레이 (원 clip 안)

- **림**: 반지름 0.74R→R radialGradient, 청백색 alpha 0 → 0.3 → 0.8 → 0.55. 실루엣 가장자리가 빛을 머금은 느낌.
- **발광 베일**: 남극 투영점(안 보이면 하단 가장자리)을 중심으로 반지름 2.1R radialGradient. alpha = `1 − (1 − veil·core)(1 − veil·skirt)(1 − haze·(1−0.5t))`, core = 가우시안 `exp(−2.2u²)`, u = t/veilR. 17개 stop. 줄눈과 하이라이트 선까지 덮어 바닥이 빛나는 효과.
- **블룸**: 극점광을 받은 타일(pole > 0.15)만 별도 캔버스에 단색으로 그려 `blur(4 + bloom·10 px)`, `lighter` 합성, alpha `bloom·0.65`.

## 6. 줄눈 빛줄기 (선택)

- 행 경계 위도선 = 가로 줄눈, 각 행의 타일 경계 경도 = 세로 줄눈. 이 그래프를 (위도, 경도) 공간에서 따라가는 경로를 만든다.
- 가로 진행 중 교차점마다 확률 `gturn` 으로 위/아래로 꺾고, 세로 줄눈은 한 행 높이에서 끝나므로 반드시 좌우로 꺾음. 직전과 같은 쪽으로는 꺾지 않아 계단형으로만 진행.
- |위도| > 60° 행은 진입 금지(극 주변 맴돎 방지), 총 경도 이동 300° 제한, z' < −0.2 면 종료.
- 이동 거리: 0.1× 속도로 hold 초 → acc 초 동안 0.1→1 지수 가속 → 등속.
- 그리기: 경로를 1° 간격 점으로 투영, 꼬리→머리로 밝아지는 프로파일, z' 가 작을수록 smoothstep 으로 흐려짐. halo(굵게, blur) + mid + core 3겹, `lighter` 가산. 색은 빨강↔초록 위상에 흰빛을 섞음.

## 7. SVG 스냅샷

- 바깥 사각형 대신 축소 polygon 에 `stroke = 옆면색`, `stroke-width = max(0.4, gap · 타일 평균 반경)`.
- 타일마다 `<linearGradient gradientUnits="userSpaceOnUse">` (수백 개 생겨도 정상).
- 림 offset 환산: 캔버스 내부반지름 0.74R 그라디언트 → SVG `0.74 + 0.26·t`.
- 블룸/빛줄기 halo: `<filter><feGaussianBlur/></filter>` + `mix-blend-mode:screen`.
- 회전 중에는 SVG 를 갱신하지 않고, 정지 시나 복사 버튼에서만 생성.
