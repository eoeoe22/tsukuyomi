# 반3D SVG/Canvas 물체 만들기

3D 메시나 라이브러리를 쓰지 않는다. 물체를 **표면 좌표로 정의 → 각도 덧셈으로 회전 → x축 회전으로 시점 기울기 → 정사영 → 법선으로 앞/뒷면 판정 → 2D 도형으로 칠하기** 순서로 처리한다. 결과는 원근 없는 일러스트 톤이고, 같은 계산 결과를 Canvas(애니메이션)와 SVG(정지 스냅샷) 양쪽으로 출력한다.

## 시작하는 법

1. 형태가 어느 유형인지 고른다 (아래 표).
2. 해당 템플릿을 복사한다. 둘 다 단일 HTML, 외부 의존성 없음, 브라우저에서 바로 동작하고 `__api.buildSVG()` 로 SVG 를 뽑는다.
3. 템플릿 안의 ①~⑤ 표시된 "바꿀 곳"만 수정한다. 투영·가시성 코드는 건드리지 않는다.
4. 세부 수식과 원본 파라미터가 필요하면 해당 reference 를 읽는다.

| 형태 | 예 | 템플릿 | 참고 |
|---|---|---|---|
| 좌우 대칭 실루엣을 세로축으로 돌린 것 + 표면 무늬 선 | 죽순, 병, 꽃병, 팽이, 달걀, 체스 말 | `templates/lathe.html` | `references/lathe.md` |
| 구 표면을 위경도 격자 조각으로 덮은 것 | 미러볼, 타일 행성, 비늘 공 | `templates/tiled-sphere.html` | `references/tiled-sphere.md` |
| 그 외 볼록 파라메트릭 곡면 | 타원체, 토러스 바깥면 | 둘 중 가까운 것에서 `project()`/`V()` 만 교체 | 아래 "확장" |

## 좌표 규약 (반드시 통일)

- 시점 좌표: x 오른쪽, y 위, z 화면 밖(관찰자 쪽). 화면 좌표는 `(Cx + S·x, Cy − S·y)` — y 부호가 뒤집힘에 주의.
- 세로축(y) 회전: 각도에 `rot` 를 더하는 것으로 끝. 행렬 불필요.
- 시점 기울기 T (양수 = 위에서 내려다봄): x축 회전
  ```js
  y' = y·cosT − z·sinT
  z' = y·sinT + z·cosT     // z' > 0 이면 관찰자 쪽
  ```
- 투영은 정사영: `x, y'` 만 쓰고 `z'` 는 가시성·밝기 판정에만 쓴다.

## 핵심 원리 6가지

1. **표면 좌표로 정의한다.** 회전체는 (높이 y, 둘레각 θ), 구는 (위도, 경도). 무늬·타일·빛줄기 경로 모두 이 좌표에서 만들고 매 프레임 투영만 다시 한다.
2. **볼록체면 z-버퍼가 필요 없다.** 법선의 z' 성분 > 0 인 점/면만 그린다. 회전체 법선 ∝ `(sin a, dr/dy, cos a)` 이므로 판정식은 `dr/dy·sinT + cos(a)·cosT > 0`. 구는 위치 벡터가 곧 법선이라 `V(...)[2] > 0`.
3. **표면 위끼리의 가림은 해석적으로.** 겹치는 무늬(죽순 껍질)는 깊이 비교 대신 "더 바깥 층의 경계선보다 아래면 덮임" 같은 규칙 함수로 판정한다.
4. **회전 불변인 것은 캐싱한다.** 회전체의 실루엣(높이별 단면 원 → 타원의 합집합)과 축대칭 음영은 세로축 회전으로 변하지 않으므로 기울기가 바뀔 때만 오프스크린에 굽는다. 매 프레임은 무늬 선만 계산.
5. **두께·재질은 2D 트릭으로.** 타일을 중심 쪽으로 `1−gap` 배 축소해 겹쳐 칠하면 줄눈과 경사면(베벨)이 생긴다. 윗변 밝은 선 + 아랫변 반투명 검은 선으로 모서리 하이라이트·그늘을 준다. 외곽선은 2배 두께로 stroke 후 fill 로 안쪽 절반을 덮는다.
6. **음영은 법선 기반 색 보간 + 그라디언트 오버레이.** 밝기 b = 환경광 + 광원항 + 프레넬 림 `(1−n.z)³` → 그늘색↔본색↔하이라이트색 보간. 조각마다 법선을 ±1° 정도 무작위로 흔들면 거울 조각 반짝임이 생긴다. 마지막에 원형 clip 안에 림 radialGradient, 발광 베일, 블룸(밝은 조각만 blur 후 가산)을 얹는다.

## 화면 크기 안정화

기울기를 바꿀 때 물체가 커졌다 작아졌다 하지 않도록, 0~90° 전 범위에서 투영 높이의 최댓값을 미리 구해 고정 배율 `S` 를 정하고, 기울기마다 세로 중심 `OY` 만 다시 맞춘다 (`lathe.html` 의 `S`, `setTilt`).

## Canvas → SVG 대응

SVG 는 "현재 회전각의 한 프레임"이다. 계산 함수(`visibleTiles()`, `visibleRuns()`)를 공유하고 출력만 바꾼다.

| Canvas | SVG |
|---|---|
| `ctx.clip(path)` | `<clipPath>` (회전체는 타원 묶음, 구는 원) |
| 바깥 사각형 fill + 축소 사각형 fill | 축소 polygon 에 옆면색 `stroke`, 두께 = gap × 타일 평균 반경 |
| `createLinearGradient` | 조각마다 `<linearGradient gradientUnits="userSpaceOnUse">` |
| `createRadialGradient(C,C,r0,...)` | `<radialGradient r=R>` + offset 을 `r0/R + (1−r0/R)·t` 로 환산 |
| `filter: blur()` + `globalCompositeOperation='lighter'` | `<feGaussianBlur>` + `style="mix-blend-mode:screen"` |
| 픽셀 단위 음영 맵(ImageData) | `<image href="data:...">` 로 삽입 |
| 2배 stroke 후 fill (외곽선) | 같은 타원 묶음을 stroke 그룹 → fill 그룹 순으로 |

## 확장: 다른 형태

- **볼록 파라메트릭 곡면**: `(u,v) → (x,y,z)` 와 법선 함수만 정의하면 `project()` 패턴 그대로 쓴다. 실루엣은 경계 샘플 또는 단면 합집합.
- **비볼록(토러스 안쪽, 손잡이 달린 컵 등)**: 법선 판정만으로는 자기 가림을 못 막는다. 면을 z' 평균으로 정렬해 뒤→앞으로 그리는 painter's algorithm 을 추가한다. 조각 수가 수천 개 이하면 충분히 빠르다.
- **원근감이 필요하면**: `scale = f / (f − z')` 를 x, y' 에 곱한다. 단 일러스트 톤과 고정 배율 계산이 깨지므로 기본은 정사영 유지.

## 흔한 실수

- 화면 y 를 `C + y` 로 써서 상하가 뒤집힌다 → 반드시 `C − y'`.
- 회전체 법선의 `dr/dy` 부호. 프로파일의 y 가 아래로 증가하는 화면 좌표이므로 법선 y 성분은 `+dr/dy` (아래로 넓어지면 위를 향함).
- 실루엣 타원의 `ry` 가 0 이 되어 정면(T=0)에서 path 가 사라짐 → `ry = max(0.75, rx·|sinT|)`.
- **회전체 표면을 높이(y) 등간격으로 훑는다** → 바닥·꼭대기처럼 프로파일이 수평에 가까운 구간은 y 가 조금만 변해도 반지름이 크게 바뀌어 샘플 사이가 비고, 아래(또는 위)에서 비스듬히 보면 그 면에 **테두리 모양 동심원 무늬**가 찍힌다. 음영 굽기처럼 표면 전체를 훑는 작업은 프로파일을 **호 길이 순서로 샘플링한 `PROFILE` 점열**을 따라가고, 법선도 이웃 점 차분 `(dy, dr)` 으로 구한다 (판정식 `dr·sinT + dy·cos(φ)·cosT > 0`).
- **반지름 표를 "정수 높이로 반올림 + max" 로 만든다** → r(y) 가 계단형이 되어 `dr/dy` 가 들쭉날쭉하고, 가장 넓은 지점(dr/dy≈0)에서 앞면 판정이 깜빡여 크게 기울였을 때 실루엣을 따라 **점선 같은 짧은 선 조각**이 생긴다. `PROFILE` 의 이웃 두 점을 선형 보간해 표를 만든다.
- 축대칭 음영의 시작 높이를 임의로 자르면 띠가 생긴다 → 음영 함수가 0 이 되는 지점(예: 가장 넓은 높이)부터 시작.
- 타일 위도 행의 시작 경도를 매 행 같게 두면 세로 줄눈이 일직선 → 행마다 무작위 오프셋, 시드 고정 PRNG(mulberry32)로 재현성 확보.
- 극 근처 행은 타일 수 최소값(4)을 두지 않으면 0 개가 되어 구멍이 난다.
- 매 프레임 실루엣/음영을 다시 구워 느려진다 → 기울기 변경 시에만.
- `prefers-reduced-motion` 사용자는 회전 정지.

## 검증

헤드리스 브라우저(Playwright)로 페이지를 띄워 `__api.setRot()`, `__api.setTilt()` 후 스크린샷, `__api.buildSVG()` 결과를 별도 페이지에 넣어 스크린샷해 Canvas 와 SVG 가 같은 그림인지 눈으로 비교한다. 기울기 −90°, 0°, +90° 극단값을 꼭 확인한다.
